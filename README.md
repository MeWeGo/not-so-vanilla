# Not So Vanilla

*Minecraft, but you're 9 again. The night is scary, the world is huge, and you don't know how anything works.*

A hard survival modpack for **Minecraft 26.2 (NeoForge)**: limb-based health and field medicine, thirst, temperature, seasons, bandits and survivors, mobs that hear you, and a world you can see for miles.

The full player-facing description is in [branding/DESCRIPTION.md](branding/DESCRIPTION.md).

## What's in this repository

The pack itself is published on Modrinth as a `.mrpack`. Third-party mods are downloaded from Modrinth when the pack is installed. This repository holds the pack's own mods and the files that build it.

| Folder | What it is |
|---|---|
| [`bandits-addon/`](bandits-addon) | **Grounded Bandits**: hostile bandits and neutral survivors who look exactly alike. Survivors fight bandits and zombies, and trade medicine for a good meal. |
| [`inventory-addon/`](inventory-addon) | **Grounded Inventory**: an Inventory tab on TarkovCraft's character screen, with Tarkov-style drag-and-drop healing onto limbs. |
| [`survival-addon/`](survival-addon) | **Grounded Survival**: realistic item weights, water bowls that track water purity, fruit juice, and fruit-tree spawning. |
| [`tweaks-src/`](tweaks-src) | **Grounded Tweaks**: a data-only mod with slower walking, the starter Food Book, Lunchbag and Field Medicine book, fixed Lunchbag and Food Book recipes, and extra limb definitions. |
| [`tweaks-src-tools/`](tweaks-src-tools) | Generator for the illustrated Field Medicine book. |
| [`overrides/`](overrides) | Configs and prebuilt jars that go into the pack. |
| [`build_pack.py`](build_pack.py) | Builds the `.mrpack` files from Modrinth version data plus `overrides/`. |
| [`branding/`](branding) | Icon (generated by `make_icon.py`) and Modrinth description. |
| [`NOTES.md`](NOTES.md) | Development notes: mod choices, test results and known issues. |

## Building

- **Mods:** each `*-addon` folder is a standard NeoForge Gradle project that needs Java 25. Run `./gradlew build`; the jar lands in `build/libs/`.
- **Grounded Tweaks:** zip the contents of `tweaks-src/` into a `.jar`.
- **Pack:** run `python build_pack.py`. The packs are written to `dist/`.
